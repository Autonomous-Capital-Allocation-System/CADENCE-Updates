# CADENCE-Updates

Public update feed for CADENCE by ACAS Tools.

The desktop app reads `update-manifest.json` when a person chooses **Check for
Updates**, compares `latestVersion` with the running build, and opens the
pages named here in the browser. Nothing is downloaded or installed
automatically.

- `update-manifest.json` — the feed (schema 1).
- `CHANGELOG.md` — what each version changed.

The manifest is edited last, after the release it announces is live.
